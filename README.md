Bengal Technologies provides a platform for API lifecycle management, enabling versioning, deprecation scheduling, and machine‑to‑machine authentication. Their portal lets developers register applications, obtain scoped credentials, and monitor usage across multiple API versions, with built‑in logging, alerts, and SDKs for popular languages. The service aims to simplify API governance without breaking existing clients.

**Areas:** Company · API Management · Versioning · Authentication · Monitoring

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Bengal Technologies: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
